# Vue Markdown Editor 

A modern **Markdown Editor with Live Preview**, built with **Vue 3**, **TypeScript**, **Vite**, and **Tailwind CSS**.  
Type Markdown on the left and see a **real-time preview** on the right.

---

##  Features

- Live Markdown editing
- Real-time preview
- Safe HTML rendering with **DOMPurify**
- Supports headers, lists, code blocks, and YAML
- Clean UI with **Tailwind CSS**
- Built with **Vue 3 + TypeScript**

---

##  Tech Stack

- Vue 3 + TypeScript  
- Vite  
- Tailwind CSS  
- Marked (Markdown parser)  
- DOMPurify (XSS protection)

---

##  Usage

1. Clone the repository:

```bash
git clone https://github.com/Oreaje/3rdSemesterAssignment.git
```

2. Navigate into the project:

```bash
cd vue-markdown-editor
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:
```bash
npm run dev
```

5. Open your browser at http://localhost:5173 and start typing Markdown.
